# Agent Router

For template work:

1. Read `README.md`.
2. Read `AGENTS.md`.
3. Read `docs/method/1c-autoresearch-process.md`.
4. Read bootstrap and validation scripts only when changing them.

For concrete research repos created from this template:

1. Read `project.toml`.
2. Read `analysis/queue/README.md`.
3. Use `scripts/queue/Get-NextAnalysisTask.ps1` to select one task.
4. Write evidence under `analysis/features/<feature-id>/`.
5. Validate with `scripts/checks/Test-ResearchRepo.ps1`.

Do not treat this template as an evidence source for any customer project.
