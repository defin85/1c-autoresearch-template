## Why

The reusable template still generates the retired queue- and dashboard-owned research contour, while verified project repositories now use one repository-owned seven-gate workflow with immutable source, diff, and MRQ generations. Folder import and other reusable source features cannot be ported safely until generated repositories share that contract.

## What Changes

- **BREAKING** Replace the generated research-repository scaffold with the repository-owned seven-gate, seven-job, eight-operation workflow contract.
- Port the reusable application service, CLI, source acquisition, immutable generation contracts, local workspace API, and verification surfaces from the verified reference implementation.
- Keep connection profiles, upload drafts, indexes, events, and folder previews in user scope; keep repository declarations and immutable generations authoritative.
- Remove generated legacy queues, compatibility readers, stage preferences, and competing research-state paths from the new scaffold.
- Add generation tests proving a fresh repository passes strict checks and exposes the same typed workflow and source declaration contract.
- Preserve the template repository's independent managed-workspace implementation until its existing uncommitted work is reconciled; this change owns the generated-repository runtime and reusable source features, not customer data.

## Capabilities

### New Capabilities

- `repository-owned-generated-research-workflow`: Fresh repositories generated by the template use the canonical workflow, immutable generations, typed operations, and user-scope operational state needed by current autoresearch features.

### Modified Capabilities

None.

## Impact

- Affects `templates/research-repo/`, reusable runtime modules and schemas under `src/one_c_autoresearch/`, bootstrap/check tooling, verification documentation, and generated-repository tests.
- Existing generated repositories are not migrated in place; users regenerate or explicitly port their canonical evidence.
- No customer binaries, absolute workstation paths, credentials, generated indexes, or project-specific research outputs are added.
