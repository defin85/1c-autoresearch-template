# __PRODUCT__ Research

Репозиторий хранит единственный исследовательский процесс: три снимка информационных баз → физические `DIF-*` → смысловые `MRQ-*` или утверждённый технический шум → производные материалы.

## Начало работы

```bash
python -m one_c_autoresearch status
python -m one_c_autoresearch next
python -m one_c_autoresearch run-next
python -m one_c_autoresearch run-until-blocked
python -m one_c_autoresearch doctor
```

Изменения выполняются только типизированной командой с текущим отпечатком процесса:

```bash
python -m one_c_autoresearch apply project.configure \
  --expected-fingerprint '<sha256:...>' \
  --payload '{"product":"...","baseline_version":"...","target_version":"...","next_vendor_version":"..."}'
```

Тот же `ApplicationService` обслуживает браузерный интерфейс. Произвольные команды и прямая замена канонических файлов не поддерживаются.

Шаг агента сначала сохраняет проверенное предложение в пользовательском каталоге и останавливается. Только следующий запуск с явным `--approve-agent-proposal` применяет это же предложение через каноническую типизированную операцию. После сбоя новое предложение не создаётся, пока сохранённое не принято или не изменились его входные отпечатки.

Подробный порядок получения исходников, индексации, `DIF → MRQ`, утверждения и восстановления описан в [методике процесса](docs/agent/research-workflow.md).

## Хранилища

- `research/` — контракты, схемы и три активных указателя;
- `sources/generations/` — неизменяемые исходники трёх ролей;
- `analysis/indexes/generations/` — неизменяемые физические различия и покрытие целевой версией;
- `analysis/migration-requirements/generations/` — неизменяемые графы MRQ;
- `outputs/` — только производные представления.

Секреты, индексы `rlm-tools-bsl`, загрузочные черновики, события и журналы находятся вне Git и могут быть удалены без изменения результата исследования.

Новые получения исходников публикуются по компонентному маршруту версии 2. Старые поколения версии 1 остаются неизменяемой историей, но не используются для новых различий и индексов. Откат выполняется возвратом ревизии репозитория средствами Git; ручной выбор старого указателя и перезапись каталога поколения не поддерживаются.

Новые поколения различий также имеют схему версии 2. Файловые строки расширений сохраняются только в `extension-physical-diff.csv`, а в основной `diff-inventory.csv` входят детерминированные вмешательства из `extension-diff.jsonl`. Зависимости, полное покрытие исходных путей и версии анализатора находятся в четырёх остальных сопутствующих файлах того же атомарного поколения. Исторические поколения различий версии 1 доступны только для чтения и не могут быть пересобраны.

Анализатор читает только проверенные компоненты `xml-hierarchical/v1` и `v8unpack/v1`, не исполняет BSL и не обращается к сети. Неподдерживаемое представление, небезопасный XML, неоднозначная идентичность или путь без доказанного семантического владельца останавливают публикацию целиком.
